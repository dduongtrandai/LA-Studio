# vietnorm upstream provenance

The initial implementation is a C++17/Qt port of `vietnormalizer` version
0.2.3 at commit `dd38778731d6ca4e9e670a19abb2df1c901a1852`.

The rule pipeline is derived from the JavaScript implementation in
`nghitts/src/utils/` and the Python port in `vietnormalizer/vietnormalizer/`.
Keep upstream attribution and review the Apache-2.0/MIT notices before moving
this module to a standalone repository.
