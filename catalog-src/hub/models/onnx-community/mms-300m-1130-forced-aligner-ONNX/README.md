# MMS Forced Aligner ONNX

ONNX export of `MahmoudAshraf/mms-300m-1130-forced-aligner` for local forced alignment workflows.

This catalog entry is marked as non-commercial because the upstream model is licensed under CC BY-NC 4.0. LA Studio should allow local download and experimentation, but commercial packaging or paid plugin distribution needs a different license or a separately licensed model.

The alignment runtime is declared as a contract only until LA Studio ships an implementation that covers audio decoding, resampling, ONNX inference, transcript normalization, CTC/Viterbi alignment, confidence scoring, and JSON/SRT/WebVTT export.
